# Инструкции для локального Codex

Назначение: прочесть реальную Miro-доску, сохранить полный текст и URL, визуально сравнить с PNG и подготовить черновой itroadmaps.course.v2.

1. Репозиторий публичный. **Не выводи и не коммить** OAuth Access Token, Client Secret, .env, cookie-профиль .local/ и приватные данные доски. Не публикуй out/ и PNG.
2. Используй только boards:read. Запусти python miro_to_md.py inspect. Не изменяй саму доску.
3. Изучи out/report.json, out/items.json, out/links.csv, out/sections.json, out/connectors.json. Проверь все встроенные ссылки, типы элементов, неприписанные разделы и порядок блоков.
4. Изучи out/preview.html, но **это не точное изображение доски**. Настоящее визуальное подтверждение — PNG из out/visual/, созданные пользователем через python visual_capture.py в локальном браузере с ручным входом. Если кадров недостаточно, попроси ещё.
5. Исправляй неверный экспорт, добавляй тесты; сохраняй все оригинальные URL и Miro object IDs. Не придумывай названия и содержание уроков, не делай OCR без явного запроса.
6. Выполни python miro_to_md.py export --slug agents-rag --title "Agents + RAG". Проверь course.json против danilfg/itroadmaps/COURSE_PACKAGE_FORMAT.md.
7. Никакой автоматической публикации, импорта или внешней передачи данных. Итог: счётчики объектов, ссылок, разделов, пропуски, отличия от PNG и проверка ZIP.
8. Если Codex запущен в облаке, локальные .env и out/ автоматически недоступны; сначала выбери среду и разрешённый способ передачи нечувствительных файлов.
